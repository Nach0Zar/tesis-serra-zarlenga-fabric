# Cliente (pendiente)

Este directorio contendrá el cliente del prototipo, que consume la interfaz pública del chaincode `snt` definida en el contrato congelado [`docs/api-contract.md`](../docs/api-contract.md) (v2.0.1).

Su desarrollo está bloqueado hasta que el contrato esté en la rama principal: por la regla de DES-5, cliente y baseline no pueden avanzar contra un contrato que aún no fue integrado.
