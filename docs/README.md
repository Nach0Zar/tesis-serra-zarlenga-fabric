# Documentacion del proyecto

La carpeta `docs/` concentra documentacion tecnica y academica del prototipo. Los archivos de este directorio deben registrar decisiones, protocolos y material de apoyo que orientan la implementacion, validacion y evaluacion del sistema.

Tipos de documentos esperados:

- protocolos de medicion y validacion experimental;
- contratos de interfaz y especificaciones tecnicas;
- documentos de diseno de arquitectura;
- decisiones de arquitectura cuando exista una plantilla aprobada;
- notas de alcance, limitaciones y criterios metodologicos;
- material de apoyo para reproducir resultados o interpretar evidencias.
