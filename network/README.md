# Red Fabric del prototipo (pendiente)

Este directorio contendrá la configuración de la red Hyperledger Fabric del prototipo:

- canal único con Private Data Collections, según ADR-002;
- una organización Fabric por establecimiento, según ADR-003;
- servicio de ordenamiento Raft de 3 nodos.

La topología física concreta (nodos, hosts, despliegue) es una decisión pendiente: ver [`docs/adr-roadmap.md`](../docs/adr-roadmap.md), decisión D2.
